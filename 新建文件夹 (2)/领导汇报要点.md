# 天猫近3个月利润分析 · 领导汇报要点

**口径**：净利润（推广后）｜**期间**：5/11–8/2（部分周缺失）｜**单位**：元

## 一句话结论

原味大大包推广前有利润，但推广后净贡献弱；近周整体利润回落，主因不是大大包，而是袋面主链接等主链/箱规恶化。

## 核心结论

1. 大大包有“利润补充”，但补不到账上：推广前有利润，推广后多被广告吃掉。
2. 近周回落：7.6-7.12 → 7.13-7.19，整体由约 -4,111 降至 -5,180（恶化约 1,069）。
3. 回落主因 ID：
   - 668566625747 袋面主链接（-667）
   - 648600900806 30包（-243）
   - 649369494424 24包经典/牛系列（-210）
4. 每周绝对亏损长期集中在袋面次链接、袋面主链接、杯面主链接；巴东牛肉持续大额亏损。

## 建议

1. 优先复盘袋面主链接推广费率与投产。
2. 同步排查 30包/24包箱规亏损。
3. 大大包严控推广侵蚀，保留推广前利润。
4. 巴东牛肉单独评估减投/停投。
