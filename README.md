### 分享给别人

`localhost` / `127.0.0.1` **不能分享**，别人的浏览器打不开你电脑上的地址。

仓库是公开的，构建好的静态站在 [`docs/`](./docs/)。当前可直接打开：

- https://raw.githack.com/ghg131419-cloud/cursor/cursor/ielts-grill-me-site-1cdd/docs/index.html

正式长期地址（需在 GitHub 打开 Pages）：

1. 仓库 **Settings → Pages**
2. Source 选 **GitHub Actions**，或 Branch 选本分支 / `main` 的 `/docs`
3. 打开后地址为：https://ghg131419-cloud.github.io/cursor/

每个人的学习进度保存在**自己浏览器**里，互不影响；可用「导出 JSON」把进度发给自己换设备。

功能：五大模块课程、本机进度保存、JSON 导入导出。
