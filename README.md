# cursor

## Impeccable design skill

[Impeccable](https://impeccable.style) is installed for Cursor under `.cursor/skills/impeccable/` (v4.1.1).

### Enable in Cursor

1. Settings → Beta → Nightly channel (restart if needed)
2. Settings → Rules → enable **Agent Skills**

### Usage

In Agent chat:

```text
/impeccable init
/impeccable audit
/impeccable polish
/impeccable critique
```

Update later with:

```bash
npx impeccable update
```
