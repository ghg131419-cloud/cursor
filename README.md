# 营多捞面 · 天猫经营仪表盘

这是按附件里的深色经营看板做的一个可交互示例：两页仪表盘，其余是明细表。数字来自仓库里的周损益 CSV 和双店订单表，不是占位数据。

浏览器版打开 `dashboard/index.html`。Excel 版是 `dashboard/营多天猫经营仪表盘.xlsx`，打开后先看「经营总览」和「双店销售」，用单元格里的下拉换周次或店铺；后面是周汇总、商品周损益和订单明细。

- 经营总览：2026-05-11 至 2026-08-02 的八个周。柱是成交金额，线是推广后净利润。浏览器里可以点周次、柱子，或用左右方向键切换；Excel 里用周次下拉。
- 双店销售：7 月 27 日–8 月 2 日旗舰店和淘宝店的商家实收、件数、成本、推广前利润，以及省份和系列。
- 商品周损益、订单明细：浏览器里可搜索、筛选、排序和翻页；Excel 里用表头筛选。

订单口径与源工作簿「字段复核」一致（已发货待签收、已签收、已发货退款成功、已签收退款成功）：商家实收 115,659，总成本 50,371。
