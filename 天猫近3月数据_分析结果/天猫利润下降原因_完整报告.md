# 天猫近3个月利润下降原因分析报告

**口径**：净利润（推广后）｜**期间**：5.11–7.26（单周）｜**单位**：元

## 一、结论摘要

1. 最好周为 **7.6-7.12（-4111）**，之后连续两周回落：
   - 7.13-7.19：**-5180**（-1069）
   - 7.20-7.26：**-5613**（较上周 -433；较最好周 -1502）
2. **利润下降分两阶段、原因不同**：
   - **阶段一（7.6→7.13）**：主要是 **推广前利润下降**。第一责任 ID：**668566625747（袋面主链接）**，推广后 -667（推广前 -597，推广费 -133）。
   - **阶段二（7.13→7.20）**：更突出的是 **推广费上升**。恶化最大 ID：**649361890551（袋面次链接）**，推广后 -259（推广前 +195，推广费 +529）。
3. 原味大大包：推广前有利润，但推广后净贡献弱，**不是两波回落的第一责任**。

## 五、建议

1. 针对阶段一：复盘袋面主链接成交与推广前利润下滑。
2. 针对阶段二：立刻压降袋面次链接、30包无效/低效推广费。
3. 巴东牛肉持续高亏损，建议减投或停投验证。
4. 大大包保留推广前利润，严控推广侵蚀。
