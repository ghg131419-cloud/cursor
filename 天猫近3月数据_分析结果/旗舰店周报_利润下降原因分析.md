# 从旗舰店周报看利润下降原因

**数据**：天猫旗舰店周报_7.27-8.2.csv（店铺级）

## 结论

利润下降分几波，原因不同：

1. **7.6→7.13（第一波）**：推广后 -4109→-5144（-1035）  
   **主因：推广前利润下降**（-3160）。推广费其实在降（-2604）。

2. **7.13→7.20（第二波）**：推广后 -5144→-5582（-438）  
   **主因：推广费上升**（+607），推广前也略降（-156）。

3. **7.20→7.27**：推广后改善到 -5089（+493）  
   推广前回升超过推广费增加。

4. **7.27→8.3（第三波）**：推广后 -5089→-5821（-732）  
   **主因：推广费上升**（投入 +3049），尽管推广前利润在升。

## 一句话

近期利润变差 = **先是生意/推广前利润走弱，后是推广费抬升过快**。店铺周报无法定位到具体商品ID。
