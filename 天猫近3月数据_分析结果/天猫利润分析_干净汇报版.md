# 天猫利润分析（干净汇报版）

**主口径**：ID周损益｜推广后净利润｜5.11–8.2（9个单周）

## 核心结论
1. 最好周 **7.6-7.12（-4,109）**，之后 7.13（-1,073）、7.20（-432）连续回落。
2. **7.6→7.13** 主因推广前利润下降。TOP3：袋面主链接 -666；24包经典/牛系列 -211；30包 -202。
3. **7.13→7.20** 更突出推广费上升，最大拖累 袋面次链接（-259）。
4. 绝对亏损长期集中在袋面主/次链、杯面主链；巴东持续亏损。大大包非第一责任。
5. 5.11→7.27 整段成交约 -9.1%，推广后亏损略收窄，不是整段“量增利降”。
